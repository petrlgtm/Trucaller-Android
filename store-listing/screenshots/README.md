# Required Screenshots

The following screenshots are required for the Play Store listing. Each screenshot should be captured at 1080x1920 (phone) or 1200x1920 (7-inch tablet) resolution.

## Phone Screenshots (minimum 2, recommended 8)

1. **01_caller_id.png** - Incoming call screen showing caller identification with spam score
2. **02_contacts.png** - Contacts list with search functionality and sync status
3. **03_spam_blocking.png** - Spam blocking screen with blocked numbers list
4. **04_profile.png** - Profile screen showing trust level, device info, and settings
5. **05_anti_theft.png** - Anti-theft dashboard with stolen device report form
6. **06_family_groups.png** - Family groups screen with member list and device status
7. **07_call_recordings.png** - Call recordings list with playback controls
8. **08_analytics.png** - Analytics dashboard with call and spam statistics

## Tablet Screenshots (optional, recommended 4)

1. **tablet_01_caller_id.png** - Caller ID on tablet layout
2. **tablet_02_contacts.png** - Contacts on tablet layout
3. **tablet_03_anti_theft.png** - Anti-theft on tablet layout
4. **tablet_04_analytics.png** - Analytics on tablet layout

## Feature Graphic

- **feature_graphic.png** - 1024x500 banner for the Play Store header

## App Icon

- **app_icon_512.png** - 512x512 high-resolution app icon

## Capture Guidelines

- Use a clean device state with realistic sample data
- Ensure dark mode and light mode variants are available
- Blur or redact any real personal information
- Use consistent device frame mockups if wrapping screenshots
